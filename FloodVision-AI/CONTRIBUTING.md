# Contributing to FloodVision-AI

We welcome improvements, feature suggestions, and bug reports for FloodVision-AI!

---

## 📋 Contribution Guidelines

1. **Branch Naming**:
   * Features: `feature/your-feature-name`
   * Fixes: `fix/your-bug-fix`
   * Documentation: `docs/your-doc-update`

2. **Code Style & Quality**:
   * Python backend code must follow PEP 8 standards.
   * Classical machine learning capacity budgets must be preserved (Students: $\le 6$ features, $\le 20$ trees, $\le 5\text{k}$ KNN pixels).
   * No deep learning or external neural pretrained weights are permitted in graded core algorithms.
   * Frontend React components should remain functional and modular.

3. **Submitting a Pull Request**:
   * Ensure both backend and frontend tests pass.
   * Provide a concise description of changes and screenshots of UI modifications.
   * Update corresponding documentation in `docs/` or `README.md`.
